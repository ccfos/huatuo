按运行环境选择部署方式。配置项见[节点配置](/docs/configuration/huatuo-bamai-configuration_zh.md)和[API 服务配置](/docs/configuration/huatuo-apiserver-configuration_zh.md)。

| 环境 | 部署方式 |
| --- | --- |
| 本地试用或容器运行 | [Docker 与 Compose](/docs/deployment/docker_zh.md) |
| Kubernetes 集群 | [DaemonSet 与 Helm](/docs/deployment/kubernetes_zh.md) |
| 由 systemd 管理的 Linux 主机 | [二进制与 RPM](/docs/deployment/systemd_zh.md) |
