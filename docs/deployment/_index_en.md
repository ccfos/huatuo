Choose a deployment method for your environment. Settings are described in [Node Configuration](/docs/configuration/huatuo-bamai-configuration_en.md) and [API Server Configuration](/docs/configuration/huatuo-apiserver-configuration_en.md).

| Environment | Deployment Method |
| --- | --- |
| Local evaluation or container runtime | [Docker and Compose](/docs/deployment/docker_en.md) |
| Kubernetes cluster | [DaemonSet and Helm](/docs/deployment/kubernetes_en.md) |
| Linux host managed by systemd | [Binaries and RPM](/docs/deployment/systemd_en.md) |
