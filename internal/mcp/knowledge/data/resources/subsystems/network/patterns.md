# 网络根因模式库

## dropwatch

| 现象 | 特征 | 典型原因 |
|------|------|---------|
| 软中断过载 | softirq CPU 占比 > 30% | 网络小包太多 |
| 网卡队列溢出 | 队列满计数增长 | 硬件层面拥塞 |
| 物理链路故障 | 错包计数增长 | 链路/网卡硬件故障 |
| 容器 PPS 限流 | PPS 超过限流值 | 平台带宽限流 |
| 虚拟桥队列溢出 | 桥接队列满计数增长 | 内核桥拥塞 |
| qdisc 丢包 | netdev_qdisc_drops_total 增长 | TC 队列规则丢包 |

## net_rx_latency

| 现象 | 特征 | 典型原因 |
|------|------|---------|
| 高延迟突发 | latency_ms 超阈值 | 用户主动取包慢/CPU 竞争 |
| 持续高延迟 | 延迟一直高 | 网卡/rss 配置问题/内核协议栈处理慢 |

## netdev_txqueue_timeout

| 现象 | 特征 | 典型原因 |
|------|------|---------|
| 驱动卡死 | 单队列 timeout | 网卡驱动 bug/hang |
| 全队列 timeout | 所有队列 timeout | 硬件故障/固件 bug |
